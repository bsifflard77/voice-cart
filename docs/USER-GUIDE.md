## Getting Started

### First Time Setup

1. **Open VoiceCartz** in your web browser
2. **Create an account** with your email and password
3. **Create your first shopping list**
4. **Start adding items** using voice or text

### Browser Requirements

- **Desktop:** Chrome, Firefox, Safari, Edge (latest versions)
- **Mobile:** Safari (iOS 12+), Chrome (Android 5+)
- **Voice Input:** Works best in Chrome; iOS Safari requires HTTPS for voice

## Creating an Account

### Registration

1. Click **"Sign up"** on the login screen
2. Enter your information:
   - First Name
   - Last Name
   - Email Address
   - Password (minimum 6 characters)
   - Confirm Password
3. Click **"Sign Up"**
4. You'll be automatically logged in and a default shopping list will be created

### Login

1. Enter your **email** and **password**
2. Click **"Sign In"**
3. Your session will persist - you won't need to login again until you logout

### Logout

- Click **"Sign Out"** in the top-right corner of any screen

## Managing Shopping Lists

### View Your Lists

All your shopping lists appear in the **"My Shopping Lists"** section. Each list shows:
- List name
- Store name
- Number of active items
- Number of picked up items
- Status (active, completed, archived)

### Create a New List

1. Click **"+ New List"** button
2. Enter a **list name** (e.g., "Weekly Groceries", "Party Supplies")
3. Select a **store** from the dropdown
4. Click **"Create List"**

The new list will be created and automatically selected.

### Select a List

- Click on any **active list** to select it
- The selected list is highlighted with a blue border
- All items you add will go to the selected list

### Complete a List

When you're done shopping:
1. Find the list you want to complete
2. Click **"Complete"** button on the list
3. The list will be marked as completed and moved to archive

### Delete a List

To permanently delete a list:
1. Find the list you want to delete
2. Click **"Delete"** button
3. Confirm the deletion when prompted
4. The list and all its items will be permanently removed

## Adding Items

### Using Voice Input

1. **Select a shopping list** first
2. Click the **microphone button** 🎤
3. **Speak clearly**: "Milk", "Bread", "Black Forest Ham"
4. The item will be automatically added and categorized

**Voice Tips:**
- Speak one item at a time
- Use natural language (e.g., "2 gallons of milk")
- Works best in quiet environments
- On iOS Safari, may require HTTPS

### Using Manual Input

1. **Select a shopping list** first
2. Type the item name in the **text input field**
3. Press **Enter** or click **"Add Item"**
4. The item will be added and categorized

**Manual Input Tips:**
- You can add quantities (e.g., "3 apples")
- Include details (e.g., "Organic bananas")
- Case doesn't matter

### Auto-Categorization

VoiceCartz automatically organizes items by department:
- **Produce** (fruits, vegetables)
- **Dairy** (milk, cheese, eggs)
- **Meat** (chicken, beef, fish)
- **Bakery** (bread, pastries)
- **Frozen** (ice cream, frozen meals)
- **Pantry** (canned goods, pasta)
- **Snacks** (chips, candy)
- **Beverages** (juice, soda, coffee)
- **Other** (miscellaneous items)

## Managing Items

### Mark as Picked Up

When you grab an item in the store:
1. Find the item in your list
2. Click the **checkmark** ✓ icon
3. The item moves to the "Picked Up" section
4. Picked up items are shown with reduced opacity

### Delete an Item

To remove an item:
1. Find the item in your list
2. Click the **trash** 🗑️ icon
3. The item is immediately removed

### View by Department

Items are automatically grouped by department in the order you'd find them in the store:
- Walk through the store in order
- Find items quickly by section
- Efficient shopping flow

## Installing as Mobile App

VoiceCartz is a Progressive Web App (PWA) that you can install on your phone or tablet for a native app experience!

### iOS (iPhone/iPad)

1. Open VoiceCartz in **Safari**
2. Tap the **Share** button (square with arrow)
3. Scroll down and tap **"Add to Home Screen"**
4. Enter a name (or keep "VoiceCartz")
5. Tap **"Add"**

**Result:**
- VoiceCartz icon appears on your home screen
- Opens as a full-screen app (no browser bars)
- Works like a native app

### Android

1. Open VoiceCartz in **Chrome**
2. Tap the **menu** (three dots)
3. Select **"Install app"** or **"Add to Home Screen"**
4. Tap **"Install"**

**Result:**
- VoiceCartz icon in your app drawer
- Full-screen native experience
- Can use offline

### Desktop (Chrome/Edge)

1. Open VoiceCartz in Chrome or Edge
2. Look for the **install icon** ⊕ in the address bar
3. Click it
4. Click **"Install"**

**Result:**
- Standalone app window
- Pin to taskbar
- Quick access

## Offline Usage

VoiceCartz works offline thanks to PWA technology!

### What Works Offline

✅ **View your shopping lists**
✅ **View items in lists**
✅ **View previously loaded data**
✅ **App interface and navigation**

### What Requires Internet

❌ Adding new items
❌ Creating new lists
❌ Marking items as picked up
❌ Deleting items
❌ Login/logout
❌ Account registration

### How It Works

1. **First Visit:** App downloads and caches essential files
2. **Subsequent Visits:** Loads instantly from cache
3. **Offline Mode:** Uses cached data when no internet
4. **Back Online:** Automatically syncs when reconnected

### Checking Offline Status

- If offline, you'll see network error messages when trying to perform actions
- The app will continue to display previously loaded data
- Changes made while offline are not saved (future enhancement)

## Tips & Tricks

### Shopping Efficiency

1. **Create List Templates**
   - Make a "Weekly Groceries" list
   - Add common items
   - Clone for each week

2. **Department Organization**
   - Items auto-sort by department
   - Follow the list order while shopping
   - Reduces backtracking in store

3. **Multiple Stores**
   - Create separate lists per store
   - Each store has its own departments
   - Switch between stores easily

### Voice Input Best Practices

1. **Clear Speech**
   - Speak clearly and at normal pace
   - Avoid background noise
   - One item at a time

2. **Natural Language**
   - "Two dozen eggs" ✓
   - "Large bananas" ✓
   - "Whole wheat bread" ✓

3. **Corrections**
   - If misunderstood, use manual input
   - Or delete and try again

### List Management

1. **Active Shopping**
   - Keep one list active per store
   - Complete when done shopping
   - Start fresh next time

2. **Planning Ahead**
   - Create lists throughout the week
   - Add items as you think of them
   - Ready when shopping day comes

3. **Multiple Lists**
   - "Walmart - Weekly"
   - "Target - Monthly"
   - "Whole Foods - Special"

### Account Security

1. **Strong Passwords**
   - Use 8+ characters
   - Mix letters, numbers, symbols
   - Don't reuse passwords

2. **Logout**
   - Logout on shared devices
   - Your data stays secure

## Troubleshooting

### Voice Input Not Working

**Problem:** Microphone button doesn't work
**Solutions:**
- Check browser permissions
- Chrome works best for voice
- iOS Safari requires HTTPS
- Try manual input instead

### Items Not Adding

**Problem:** Items won't add to list
**Solutions:**
- Check internet connection
- Ensure list is selected
- Try refreshing the page
- Check if logged in

### App Not Installing

**Problem:** Can't install as app
**Solutions:**
- Use supported browser (Chrome, Safari)
- Check iOS/Android version
- Clear browser cache
- Visit app URL directly

### Sync Issues

**Problem:** Changes not saving
**Solutions:**
- Check internet connection
- Refresh the page
- Logout and login again
- Clear browser cache
